TASSO CELL — PROJETO PRONTO PARA VS CODE

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Para usar como site estático, abra index.html com Live Server.

As imagens de referência dos aparelhos são carregadas de páginas públicas do Wikimedia Commons. A logo enviada pelo usuário está em assets/logo/tasso-cell-logo.jpg.

Observação: o número do WhatsApp está configurado em js/data.js. Troque TASSO_CONFIG.whatsapp pelo número real antes de publicar.
